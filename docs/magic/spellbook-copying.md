# Wizard-to-Wizard Spellbook Copying

*From* `#crucial-player-info` *· posted by Ham*

## Key points

- Normal spells can be shared. **Faction spells cannot.**
- Special rewards need DM approval.
- Each character may take part in up to **two** spell-copying transactions.
