# DNDA Aliases

Custom Avrae aliases made for DNDAnonymous.

## DM check and save requests

DMs use these to ask a player for a roll. The bot posts a request card with the DC.

```text title="How to use"
!command @player DC
```

```text title="Example: ask Sanctuum for a DC 15 Perception check"
!perch @Sanctuum 15
```

=== "Saving throws"

    | Save | Command |
    |------|---------|
    | Strength | `!strsa` |
    | Dexterity | `!dexsa` |
    | Constitution | `!consa` |
    | Intelligence | `!intsa` |
    | Wisdom | `!wissa` |
    | Charisma | `!chasa` |

!!! tip "Players: answering a request"
    When a DM asks for a roll, reply with the normal Avrae command, e.g. `!check perception` or `!save dex`. See the [Avrae Cheat Sheet](avrae-cheat-sheet.md).
